# Whizi field guides

A static build of the Whizi field guides: short, practical notes on using several AI models together and on what AI subscriptions really cost. Written by Nour, founder of [Whizi](https://whizi.io/), the workspace that puts 280+ models in one chat.

Read online: https://whizi-field-guides.readthedocs.io/

Guides in this image:

- [How to use multiple AI models together](https://whizi.io/resources/how-to-use-multiple-ai-models-together/)
- [AI subscription costs: calculate your true monthly spend](https://whizi.io/resources/ai-subscription-costs/)

Run it locally:

```
docker run --rm -p 8080:80 bonour/whizi-field-guides
```

Then open http://localhost:8080. Source: https://github.com/BoNour/whizi-field-guides
